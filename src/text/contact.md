Pick the channel that fits what you need. Each one reaches the people who build Whiteheap, and each is public except the one for security problems.

## A bug or a feature request

Open an issue on the tool's repository: [residue's issues](https://github.com/whiteheap/residue-cli/issues). Say which version you run (`residue --version`), your platform and the command you ran. For this website, use [whiteheap.com's issues](https://github.com/whiteheap/whiteheap.com/issues).

## A security problem

Report it privately, never in a public issue: through [residue's security advisories](https://github.com/whiteheap/residue-cli/security/advisories/new) for residue, or [whiteheap.com's](https://github.com/whiteheap/whiteheap.com/security/advisories/new) for this site. [security.txt](https://whiteheap.com/.well-known/security.txt) lists the same two addresses.

## Anything else

Send a message to [@whiteheaphq on X](https://x.com/whiteheaphq). Whiteheap is built by [Trevor I. Lasn](https://www.trevorlasn.com).
