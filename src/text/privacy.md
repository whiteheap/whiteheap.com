whiteheap.com sets no cookies, loads no analytics or tracking script, and has no forms and no accounts. It is a set of static pages.

## What a visit sends

Cloudflare serves whiteheap.com. Like any web server, it receives what your browser sends with each request, including your IP address and user agent, and handles it under [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/). Whiteheap runs no code of its own on those requests: the site is static files, with no server script.

## The tools

residue runs on your machine. Its stats ledger, which records what it freed, stays in a local file and never leaves the machine. `residue watch` runs `git fetch` against the remotes your worktrees' branches already track. Installing residue downloads it from Homebrew, a signed apt, dnf or pacman repository, or a GitHub release, under those services' own policies.

residue-ui, the Mac app, makes no network request of its own; only `residue watch` and the app's Preview fetch, from your repositories' remotes. Its settings stay on your Mac, in `~/Library/Application Support/com.whiteheap.residue/`. Installing it downloads it from a GitHub release.

## Links out

Links to GitHub, X and other sites take you to services with their own privacy policies.
